FUNFERNUS BANK BOT 4.4.0

1. Загрузите содержимое папки discord-bot в корень проекта бота.
2. Скопируйте .env.example в .env и заполните значения.
3. Запустите бота командой: python bot.py
4. В нужном текстовом канале config выполните /настроить_банк.
5. Через панель выберите каналы, роли, администраторов, тексты и файловые баннеры.
6. Через «Опубликовать панели» создайте или обновите банковские сообщения.

Обязательные переменные:
DISCORD_TOKEN
GUILD_ID
OWNER_IDS
TECHNICAL_BOT_ID

Необязательные:
BRIDGE_TIMEOUT_SECONDS=25
CONFIG_CHANNEL_ID=ID_КАНАЛА_CONFIG
SERVER_TIMEZONE=Europe/Moscow

CONFIG_CHANNEL_ID позволяет автоматически восстановить панель config после запуска. Вместо него можно один раз выполнить /настроить_банк.

Важно: через Discord настраивается только интерфейс бота. Экономика банка, цены, лимиты, игровые сообщения и ответы команд меняются только в YAML-файлах Minecraft-плагина на хостинге.

При обновлении сохраняйте папку data целиком.
